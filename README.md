# Ison Travel

Сайт туркомпании Ison Travel (Ташкент): походы выходного дня, треккинг, корпоративные выезды.

План разработки — [docs/PLAN.md](docs/PLAN.md).
Прототип дизайна в чистом HTML — [design/](design/) (референс, в сборку не входит).

## Запуск

```bash
npm install
npm run dev        # http://localhost:3000
```

| Команда | Что делает |
|---|---|
| `npm run dev` | дев-сервер с HMR |
| `npm run generate` | статическая сборка в `.output/public` — то, что уезжает на хостинг |
| `npm run build` | то же самое плюс серверная часть |
| `npm run preview` | посмотреть собранное |

## Стек

Nuxt 4 (пререндер всех страниц), TypeScript, Tailwind CSS 4 с CSS-first конфигом, `@nuxtjs/seo`, `@nuxt/image`, `@nuxt/icon`, `@vueuse/nuxt`.

Сайт полностью статический: бэкенда нет. Все страницы отдаются готовым HTML — это условие работы SEO.

## Структура

```

  components/

  composables/

    useTourFilters.ts   фильтры каталога, состояние живёт в URL

    usePhoneMask.ts     маска +998
```

Имена компонентов Nuxt собирает из папки и файла: `components/ui/Button.vue` → `<UiButton>`.

## Данные

Лежат в `app/data/*.json`, читаются через `useCatalog()` и `useNews()`. Формы описаны в `app/types/index.ts` так, как их потом отдаст бэкенд — при переходе на API меняется только композабл, компоненты остаются как есть.

## Заявки

Форма одна — `FormLead`, она же в модалках записи на тур и в расписании. Все отправки идут через `useLead()`. Сейчас это заглушка с имитацией сети и всеми состояниями (отправка, успех, ошибка).

Чтобы подключить приём заявок, меняется **только тело `send()`** в `app/composables/useLead.ts`. Ни одна форма при этом не трогается. Туда же вешается цель аналитики: успех фиксируется в этой функции, а не по переходу на отдельную страницу «спасибо» — для статики это надёжнее.

## Палитра

Вариант «Логотип»: снят пиксельно с эмблемы в Telegram-канале и доведён до рабочих контрастов.

| Токен | Значение | Контраст |
|---|---|---|
| `--color-primary` | `#4F7A12` | 5.1:1 на белом |
| `--color-accent` | `#F0A412` | только с тёмным текстом |
| `--color-on-accent` | `#2E1409` | 7:1 на акценте |
| `--color-ink` | `#2E1409` | |

`@theme static` обязателен: без него Tailwind вырезает токены, на которые пока нет ссылок в разметке.

Сравнение пяти рассмотренных палитр сохранено в [design/palettes.html](design/palettes.html).

## SEO

- Пререндер всех публичных страниц
- `sitemap.xml` и `robots.txt` генерируются файлами
- Schema.org: `LocalBusiness`, `Product` + `Offer`, `Event` на каждый выезд, `TouristAttraction`, `FAQPage`, `Review` + `AggregateRating`, `Person`, `Article`, `BreadcrumbList`
- Canonical и OG на всех страницах
- Комбинации фильтров в каталоге закрыты `noindex, follow` — это дубли

## Деплой на GitHub Pages

Workflow лежит в [.github/workflows/deploy.yml](.github/workflows/deploy.yml), собирает на каждый push в `main`.

В настройках репозитория: **Settings → Pages → Source: GitHub Actions**, затем **Settings → Secrets and variables → Actions → Variables**:

| Переменная | Значение |
|---|---|
| `SITE_URL` | полный адрес сайта, например `https://isontravel.uz` |
| `BASE_URL` | `/` для корня домена, `/имя-репозитория/` для проектного сайта |

### Важно про адрес

Выбирайте один из двух вариантов:

1. **Репозиторий `<логин>.github.io`** или свой домен — сайт в корне, `BASE_URL=/`. Работает всё.
2. **Обычный репозиторий** — сайт по адресу `<логин>.github.io/<репозиторий>/`, `BASE_URL=/имя-репозитория/`.

Во втором случае **`robots.txt` не генерируется**, и это не баг: поисковик ищет его только в корне домена, а в подпапку положить нельзя. Сборка это учитывает и файл не создаёт.

Для боевого сайта нужен первый вариант. Второй годится, чтобы показать результат заказчику.

Файл `public/.nojekyll` обязателен: без него GitHub Pages игнорирует папку `_nuxt` со всеми стилями и скриптами, потому что она начинается с подчёркивания.

## Что ещё не сделано

- **Узбекская версия.** Инфраструктура не подключена намеренно: перевод требует узбекских текстов маршрутов и направлений от заказчика. Наполовину переведённый сайт хуже русского.
- **Тексты направлений** — сейчас по 250–300 слов. Для органики нужно 800+ на каждое, это задача заказчика.
- **Фотографии** — стоковые заглушки в `public/img/stock/`. Меняются на реальные кадры без правок кода, пути лежат в `app/data/*.json`.
- **Карта маршрута** нарисована схемой, а не тайлами: треков GPX пока нет. Компонент `TourRouteMap` меняется на Leaflet, разметка вокруг остаётся.
- **Онлайн-оплата** (Payme/Click) — нужен бэкенд.
