# Ison Travel — план разработки фронтенда

Сайт для туркомпании Ison Travel (Ташкент): походы выходного дня, треккинг, корпоративные выезды.
Текущий этап — **только фронтенд**. Бэкенда нет, все данные берём из локальных JSON, структуру данных сразу делаем такой, чтобы потом подменить на API без переписывания компонентов.

---

## 1. Цели сайта

| Цель | Как измеряем |
|---|---|
| Принимать заявки на туры 24/7, без личных сообщений | Заявки с форм |
| Продавать корпоративные выезды юрлицам | Заявки на КП со страницы `/corporate` |
| Собирать органический трафик из поиска | Позиции по «туры выходного дня Ташкент», «поход Чимган», «тимбилдинг на природе Ташкент» |
| Снять недоверие к 100% предоплате | Страницы «О нас», отзывы, оферта, официальность |
| Не требовать от заказчика ведения сайта | Новости автоматически подтягиваются из Telegram-канала |

**Главная аудитория:** 80%+ заходят с телефона → всё проектируем mobile-first.

## 2. Стек

| Что | Чем | Почему |
|---|---|---|
| Фреймворк | **Nuxt 4** (SSR + prerender) | Без серверного рендера SEO не будет работать. Плюс готовые модули под sitemap, schema, i18n. Взят Nuxt 4, а не 3: тройка в режиме поддержки, структура та же — исходники в `app/` |
| Язык | TypeScript | Типы на данные туров — страхует при переходе на API |
| Стили | Tailwind CSS | Скорость, единая шкала отступов |
| Анимации | `@vueuse/motion` + GSAP ScrollTrigger (точечно) | Scroll-reveal и параллакс |
| Слайдеры | Swiper | Галереи, отзывы, reels |
| Карты | Leaflet + OpenStreetMap | Бесплатно, без ключей и лимитов |
| Иконки | `@nuxt/icon` (Lucide) | Единый стиль |
| Картинки | `@nuxt/image` | WebP/AVIF, адаптивные размеры, lazy |
| SEO | `@nuxtjs/sitemap`, `@nuxtjs/robots`, `nuxt-schema-org`, `@nuxtjs/seo` | Микроразметка и карта сайта из коробки |
| Языки | `@nuxtjs/i18n` | ru / uz, позже en |
| Формы | `vee-validate` + `zod` | Валидация и типы одной схемой |
| Состояние | Pinia (минимально: фильтры, корзина заявки) | |
| Контент | JSON в `data/` → позже API | Фронт не зависит от источника |

> Если есть причина взять другой стек — скажи до старта спринта 0, после него переезд дорогой.

## 4. Дизайн-система

Задать до первой страницы, иначе потом переделывать весь сайт.

### Палитра

| Токен | Значение | Применение |
|---|---|---|
| `--forest` | `#1C4634` | Основной, хедер, тёмные секции |
| `--forest-deep` | `#12301F` | Футер, оверлеи на фото |
| `--amber` | `#E8762C` | CTA, акценты, активные состояния |
| `--amber-soft` | `#FBE9DA` | Фон бейджей, подсветка |
| `--stone` | `#F6F3EE` | Фон страницы |
| `--graphite` | `#1A1A18` | Текст |
| `--muted` | `#6B6B63` | Вторичный текст |
| `--line` | `#E3DED5` | Границы, разделители |

Сложность туров — отдельная шкала: лёгкая `#4C9A5A`, средняя `#E8A33D`, сложная `#D2552F`.

### Типографика

- Заголовки: **Unbounded** (600/700) — характерная, есть кириллица и латиница
- Текст: **Manrope** (400/500/600)
- Шкала: 12 / 14 / 16 / 18 / 22 / 28 / 36 / 48 / 64 / 80
- Заголовки на мобильном не меньше 28px, hero — `clamp()`

### Сетка и ритм

- Контейнер 1280px, боковые отступы 20px (моб) / 40px (десктоп)
- Вертикальный ритм секций: 64px моб / 120px десктоп
- Радиусы: 12px карточки, 999px кнопки и бейджи
- Тени мягкие и редкие — основной приём глубины это фото, а не тени

### Принципы

1. **Фото — главный герой.** У заказчика сильный визуал из гор, его и показываем крупно. Минимум декора.
2. Много воздуха, крупная типографика, широкие полноэкранные кадры.
3. Анимации сдержанные: `fade-up` при скролле (60–80px, 400–600ms, ease-out), параллакс только в hero, hover-зум фото 1.05.
4. `prefers-reduced-motion: reduce` — отключает все движения. Обязательно.
5. Любое состояние проектируем целиком: загрузка (скелетон), пусто, ошибка, успех.
6. Фокус виден всегда, контраст текста ≥ 4.5:1, попадание по тапу ≥ 44px.

## 6. Страницы детально

### 6.1. Главная — `/`

**Задача:** за 5 секунд объяснить кто мы, и увести на ближайший выезд.

**Секции сверху вниз:**

1. **Hero.** Фоновое видео из их походов (muted, loop, постер-картинка, на мобильном — статичный кадр ради трафика и LCP). H1 «Походы выходного дня из Ташкента», подзаголовок, две кнопки: «Ближайшие выезды» (основная) и «Корпоративный тур» (вторичная). Снизу строка доверия: количество туров, участников, год основания. Индикатор скролла.
2. **Ближайшие выезды.** 4 карточки ближайших дат. На карточке: фото, название, дата, сложность цветным бейджем, цена, «осталось N мест», кнопка «Записаться». У самого ближнего выезда — таймер обратного отсчёта. Ссылка «все даты» → `/schedule`.
3. **Направления.** Плиточная сетка-мозаика: Чимган, Чарвак, Ойгаинг, Бельдерсай, Палтау, Гулькам, Сукок, Мазаржан. Каждая плитка — ссылка на SEO-лендинг направления. Это ещё и основная внутренняя перелинковка.
4. **Как это проходит.** 4 шага: выбрали тур → записались → оплатили → поехали. Горизонтальная линия-прогресс, заполняется при скролле.
5. **Reels-лента.** Горизонтальный скролл вертикальных видео (как сторис). Клик → полноэкранный просмотр.
6. **Корпоративный баннер.** Широкий блок с кадром с тимбилдинга UzMetr, цифра «35 участников», CTA «Получить КП» → `/corporate`.
7. **Отзывы.** Слайдер: скриншоты из Telegram + текстовые отзывы, средний рейтинг.
8. **Гиды.** Карточки: Исон, Ильвина, Иброхим, Абдулазиз — фото, стаж, направления. Люди едут за людьми.
9. **Новости.** 3 последних поста из Telegram + кнопка «подписаться на канал».
10. **FAQ.** 5 главных вопросов аккордеоном.
11. **Финальный CTA** с короткой формой: имя, телефон, тур.

**Интерактив и дизайн:**
- Параллакс фона в hero (трансформ 0.3 от скролла, выключается при reduced-motion)
- `fade-up` каскадом для карточек: задержка 80ms между соседними
- Счётчики цифр анимируются при попадании в вьюпорт один раз
- Hover на карточке тура: фото зум 1.05, тень поднимается, стрелка уезжает вправо
- На мобильном — липкая нижняя панель «Ближайший выезд · 330 000 · Записаться», появляется после 1-го экрана

**SEO:**
- `title`: «Походы и туры выходного дня из Ташкента — Ison Travel»
- `description` до 160 символов с ценой и частотой выездов
- Ровно один H1, остальные секции — H2
- Schema: `Organization`, `LocalBusiness`, `WebSite` c `SearchAction`
- Ссылки на все ключевые разделы прямо с главной
- LCP-картинка hero — `preload`, остальное lazy

### 6.2. Каталог туров — `/tours`

**Задача:** дать быстро найти подходящий тур и уйти в карточку.

**Состав:**
- Шапка раздела: H1, подзаголовок, количество туров
- Панель фильтров: направление, сложность (лёгкий/средний/сложный), длительность (1 день / 2 дня / с ночёвкой), цена (ползунок), сезон, тип (треккинг, пещеры, озёра, корпоратив)
- Сортировка: по дате, по цене, по популярности
- Переключатель вида: сетка / список / на карте
- Сетка карточек, подгрузка «Показать ещё»
- Блок SEO-текста внизу (200–300 слов, не мешает интерфейсу)

**Интерактив и дизайн:**
- Фильтры применяются без перезагрузки, **но пишутся в URL** (`/tours?difficulty=easy&destination=chimgan`) — чтобы ссылку можно было скинуть и чтобы поисковик видел состояние
- На мобильном фильтры — bottom sheet со счётчиком «Применить (12)»
- Скелетоны вместо спиннера
- Пустой результат: иллюстрация + «сбросить фильтры» + 3 популярных тура
- Чипсы активных фильтров сверху, каждый снимается крестиком

**SEO:**
- `ItemList` schema на список
- Первая страница рендерится на сервере
- `canonical` без параметров фильтров, комбинации фильтров — `noindex, follow`
- Хлебные крошки + `BreadcrumbList`

### 6.3. Карточка тура — `/tours/[slug]`

Самая важная страница по конверсии. Разбираем подробно.

**Состав:**

1. **Галерея-шапка.** Слайдер 3–8 фото, бейдж сложности, кнопка «все фото» → лайтбокс.
2. **Заголовок и факты.** H1 с названием, под ним строка иконок: дистанция (2.5 км), набор высоты, длительность (1 день), сложность, выезд (6:00), возврат (~18:00).
3. **Блок брони.** Десктоп — липкий справа; мобильный — закреплённая панель снизу. Внутри: цена, ближайшая дата, «осталось N мест», кнопка «Записаться», мелким — «место закрепляется после 100% оплаты».
4. **Описание маршрута** — 2–4 абзаца живым языком.
5. **Карта.** Leaflet с треком GPX + высотный профиль маршрута. Сильно повышает доверие.
6. **Что входит / не входит** — две колонки, галочки и крестики.
7. **Что взять с собой** — чек-лист с иконками (обувь, вода, перекус, тёплая кофта, аптечка).
8. **Программа по часам** — вертикальный таймлайн: 6:00 выезд с точки сбора → 8:00 прибытие → 8:30 старт → … → 18:00 возвращение.
9. **Гиды этого тура** — мини-карточки.
10. **Фото участников** прошлых выездов этого маршрута.
11. **Отзывы по этому туру.**
12. **FAQ по туру** — 4–6 вопросов.
13. **Ближайшие даты** — список дат с ценой и кнопкой.
14. **Похожие туры** — 3 карточки.

**Интерактив и дизайн:**
- Лайтбокс: свайп, зум, клавиатура, счётчик «3 / 12»
- Карта подгружается только при попадании в вьюпорт (тяжёлая)
- Таймлайн: точки подсвечиваются по мере скролла
- Кнопки «поделиться» — Telegram, WhatsApp, копировать ссылку
- Якорное меню-таб при длинном скролле: Описание · Маршрут · Программа · Отзывы

**SEO:**
- `TouristTrip` + `Offer` (цена, валюта UZS) + `Event` на каждую дату выезда + `AggregateRating` + `FAQPage`
- Уникальные title/description на каждый тур, в title цена и регион
- OG-картинка — первое фото тура
- Хлебные крошки: Главная → Туры → Направление → Тур
- Перелинковка: ссылка на страницу направления и на похожие туры

### 6.5. Корпоративные туры — `/corporate`

Отдельная посадочная под B2B. Самый денежный сегмент — страница должна выглядеть как коммерческое предложение, которое не стыдно отправить директору.

**Состав:**
1. Hero с кадром с корпоратива: «Тимбилдинг на природе для вашей команды», CTA «Получить КП»
2. **Боли:** команда выгорела · новички не знакомы с коллективом · нужен корпоратив не в ресторане
3. **Форматы:** тимбилдинг с активностями, выездной день, поход, квест на природе, зимний выезд — карточки с фото и примерной ценой
4. **Кейс UzMetr:** 35 участников, лес Сукок, золотая осень — фото, цифры, цитата заказчика
5. **Что берём на себя:** транспорт, гиды, питание, снаряжение, фото- и видеоотчёт, страховка
6. **Калькулятор бюджета:** количество человек + формат + сезон → вилка стоимости и кнопка «Отправить КП»
7. **Блок официальности:** работаем по договору и безналичному расчёту, предоставляем счёт, акт и все закрывающие документы
8. **Логотипы клиентов**
9. **Форма заявки на КП:** компания, контактное лицо, телефон, количество человек, желаемая дата, формат
10. **FAQ для юрлиц:** договор, предоплата, НДС, перенос даты, что при плохой погоде

**Интерактив и дизайн:**
- Калькулятор пересчитывает вилку сразу при изменении ползунка количества человек, без кнопки
- Кейс оформлен как мини-история с фото до/во время/после
- Форма короткая, телефон с маской `+998 (__) ___-__-__`
- Тон страницы деловой: меньше эмодзи, больше цифр и документов

**SEO:**
- Ключи: «корпоративный тур Ташкент», «тимбилдинг на природе Ташкент», «выездной корпоратив Узбекистан»
- Schema: `Service` + `Offer` + `FAQPage`
- Это страница, ссылку на которую будут отправлять в мессенджерах → OG-картинка обязательна и должна хорошо выглядеть в превью Telegram

### 6.8. Новости — `/news` и `/news/[slug]`

Лента подтягивается из Telegram-канала. На этапе фронта — мок в `data/news.json` со структурой, совпадающей с будущим ответом парсера.

**Состав:** сетка постов (фото, первые строки, дата, просмотры), фильтр «Анонсы / Отчёты / Полезное», страница поста с галереей и кнопкой «читать в Telegram».

Отдельно — SEO-статьи, которые пишем сами: «Что взять в однодневный поход», «Чимган зимой: что нужно знать», «Как подготовиться к первому треккингу».

**SEO:** `BlogPosting` / `Article`, дата публикации и обновления, автор, хлебные крошки, перелинковка на туры по теме статьи.

---

### 6.9. О нас — `/about`

История компании, философия, команда гидов крупными карточками с переходом на `/guides/[slug]`, цифры (лет в работе, туров проведено, участников), блок об официальности и безопасности, фото «за кадром».

**SEO:** `AboutPage` + `Organization`, ключ «Ison Travel» и имена гидов — по ним ищут напрямую.

---

### 6.10. Гид — `/guides/[slug]`

Фото, стаж, направления, личная история, туры этого гида, отзывы о нём. Люди записываются к конкретному человеку — это работает и даёт дополнительные страницы в индексе.

**SEO:** `Person` schema.

---

### 6.11. Отзывы — `/reviews`

Скриншоты из Telegram, текстовые отзывы, видеоотзывы, средний рейтинг, фильтр по турам, форма «оставить отзыв».

**SEO:** `Review` + `AggregateRating`. Отзывы должны быть в HTML, а не подгружаться скриптом, иначе поисковик их не увидит.

---

### 6.12. FAQ — `/faq`

Аккордеон по категориям: подготовка и снаряжение · оплата и отмена · безопасность · корпоративы · дети и новички. Поиск по вопросам. Внизу — «не нашли ответ» с контактами.

**SEO:** `FAQPage` — даёт расширенный сниппет в выдаче.

---

### 6.13. Контакты — `/contacts`

Телефоны (кликабельные `tel:`), Telegram, Instagram, точка сбора на карте, часы работы, форма обратной связи, реквизиты для юрлиц.

**SEO:** `LocalBusiness` с адресом, координатами и часами работы.

---

### 6.14. Запись — модалка + `/booking/[dateId]`

Три шага: тур и дата → участники (имя, телефон, количество) → подтверждение. Прогресс-бар, валидация на каждом шаге, маска телефона, явное согласие с условиями отмены (у заказчика предоплата невозвратная — это надо показать до отправки, а не после).

На этапе фронта заканчивается экраном «Заявка отправлена» и редиректом на `/thank-you`.

`noindex`.

---

### 6.15. Служебные

- `/thank-you` — спасибо, что будет дальше, кнопка «написать в Telegram». Нужна как цель в аналитике. `noindex`
- `/offer`, `/privacy`, `/cancellation` — оферта, политика данных, условия отмены. Ссылки в футере. Для доверия и для будущего подключения Payme/Click
- `/404` — крупная типографика, фото гор, кнопки на главную и в каталог, 3 популярных тура

## 7. Сквозные компоненты

**Хедер.** Лого, меню (Туры · Расписание · Корпоративным · Галерея · О нас · Контакты), переключатель ru/uz, телефон, кнопка «Записаться». При скролле вниз прячется, вверх — появляется, с фоном-блюром. На мобильном — бургер и полноэкранное меню.

**Футер.** Колонки: навигация · направления (SEO-ссылки на все лендинги) · контакты · соцсети. Подписка на Telegram-канал. Ссылки на оферту и политику. Копирайт и «сайт разработал …».

**Глобально:** модалка записи, тосты, скелетоны, кнопка «вверх», плавающая кнопка Telegram, липкий мобильный CTA, минимальный cookie-баннер.

## 8. SEO-чеклист

**Техническое**
- [ ] SSR или prerender для всех публичных страниц
- [ ] Уникальные `title` (≤60) и `description` (≤160) на каждой странице
- [ ] Ровно один `H1` на странице, иерархия H2/H3 не нарушена
- [ ] ЧПУ латиницей, без параметров в индексируемых URL
- [ ] `canonical` на каждой странице
- [ ] `sitemap.xml` с датами изменения + `robots.txt`
- [ ] `hreflang` для ru/uz
- [ ] 301 на один вариант домена, везде https
- [ ] Страница 404 отдаёт код 404, а не 200

**Разметка Schema.org**
- [ ] `Organization` + `LocalBusiness` — глобально
- [ ] `TouristTrip` + `Offer` + `Event` — туры и даты
- [ ] `TouristAttraction` + `Place` — направления
- [ ] `FAQPage` — FAQ, туры, корпоративная
- [ ] `Review` + `AggregateRating` — отзывы
- [ ] `BreadcrumbList` — все вложенные страницы
- [ ] `Article` — блог, `Person` — гиды

**Контент**
- [ ] Уникальный текст на каждом лендинге направления (800+ слов)
- [ ] Осмысленные `alt` у всех фото
- [ ] Внутренняя перелинковка: тур ↔ направление ↔ похожие туры
- [ ] Цены, даты и условия отмены явно на странице

**Скорость (Core Web Vitals)**
- [ ] LCP < 2.5s — hero-картинка в `preload`, видео с постером
- [ ] CLS < 0.1 — у всех картинок заданы width/height
- [ ] INP < 200ms — тяжёлые блоки (карта, лайтбокс) грузятся лениво
- [ ] WebP/AVIF, адаптивные `srcset`
- [ ] Шрифты: `preconnect` + `font-display: swap`, только нужные начертания
- [ ] Lighthouse ≥ 90 по всем четырём метрикам на мобильном

**Подключить при запуске**
- [ ] Google Search Console, Яндекс.Вебмастер
- [ ] Google Analytics 4 + Яндекс.Метрика с вебвизором
- [ ] Цели: отправка заявки, клик по телефону, клик в Telegram, заявка на КП
- [ ] Google Business Profile (локальная выдача по Ташкенту)
